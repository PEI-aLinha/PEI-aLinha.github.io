# Notes

- Prototype review:

  - Integrations:

    - For usability, group related services on the same row (e.g. "identity and mail").

  - Risks:

    - Provide an Excel template where the levels and the formula are editable.

    - In a more advanced version, move this into the interface.

  - AI:

    - In the CISO and consultant views, allow starting a conversation from a specific question. For example, when submitting a document, a button opens a conversation with the context of the current task and the AI says whether the document is correct.

    - Add the same option to the risks section.

    - Consultant conversations: show company information next to the chat (classification, submitted documents, etc.).

    - For example, when the consultant asks "help me understand the risks", the AI in the CISO context answers which standards apply, which calculation is used, whether an assessment already exists, etc.

  - Results and roadmap:

    - Improve visual hierarchy, e.g. highlight the next action.

    - Review Nielsen's heuristics.

    - Try new ways of presenting the data, such as timelines and a sense of progression.

  - If there are no risks, do not show the "how risks change the roadmap" dropdown.

  - Decide which elements deserve a background and which do not.

  - Add a wizard-style helper UI.

  - Add onboarding.

- Write a usability test script with at least 10 questions, ideally 15.

- Switch everything to semantic HTML, since performance is currently low.

- Add colour-blind modes to fix the lack of contrast.

- Presentation: show how we will improve based on the usability test feedback.
